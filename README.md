# ABAP Study

SAP ABAP 개발 실습용 저장소입니다.  
로컬 Docker 기반 ABAP Trial 환경에서 작성한 예제 프로그램을 `abapGit`을 통해 GitHub와 연동하여 관리합니다.

## 개발 환경

| 항목 | 내용 |
|---|---|
| SAP System | ABAP Cloud Developer Trial |
| 실행 환경 | Docker |
| 접속 방식 | SAP GUI |
| 버전관리 | abapGit |
| Git 저장소 | GitHub |
| 주요 실습 | ABAP Report, Internal Table, ALV, Open SQL, Class |
